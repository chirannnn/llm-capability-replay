# Evidence

This directory contains structured evidence from discovery, replay, and handoff runs.

## Structure

```
evidence/
├── discovery-YYYYMMDD-HHMMSS/    # LLM discovery evidence
│   ├── discovery.log              # Structured log events
│   ├── execution-trace.json       # LLM action sequence
│   ├── artifact.json              # Generated Capability Artifact
│   ├── screenshots/               # Browser screenshots
│   └── report.md                 # Discovery summary
├── replay-YYYYMMDD-HHMMSS/       # Deterministic replay evidence
│   ├── replay.log                 # Structured log events
│   ├── execution-trace.json       # Step execution sequence
│   ├── artifact.json              # Artifact used for replay
│   ├── screenshots/               # Browser screenshots
│   └── report.md                 # Replay summary
└── handoff-YYYYMMDD-HHMMSS/      # Human handoff evidence (within replay directories)
    └── replay.log                 # Handoff events (created, started, ended, resumed)
```

## Discovery Evidence

Generated by: `pnpm --filter api discovery:demo --goal "your goal here"`

Contains:
- **Goal**: Natural language goal provided by user
- **Observation**: UI elements observed during discovery
- **Decision**: LLM decisions for each action
- **Action**: Structured actions executed (navigate, click, type, select, wait, extract)
- **Trace**: Complete execution trace with timestamps
- **Artifact**: Final Capability Artifact generated from trace
- **Screenshots**: Browser screenshots at key points
- **Report**: Human-readable summary

## Replay Evidence

Generated by: `pnpm --filter api replay --artifact mariner-pro`

Contains:
- **Artifact**: Capability Artifact used for replay
- **Steps**: Executed steps in order
- **Action Results**: Success/failure for each action
- **Checkpoint Results**: Pass/fail for each checkpoint
- **Retry Attempts**: Retry count and backoff information
- **Outputs**: Extracted outputs
- **Screenshots**: Browser screenshots at key points
- **Report**: Human-readable summary

## Handoff Evidence

Generated by: `pnpm --filter api handoff:demo --artifact mariner-pro`

Handoff events are logged in `replay.log` within replay evidence directories:

- **handoff_created**: Reason, currentStep, currentUrl
- **handoff_started**: When human control begins
- **handoff_ended**: humanAction, when human control ends
- **handoff_resumed**: checkpointPassed, when automation resumes

## Security

Evidence does NOT contain:
- API keys
- Passwords
- Credentials
- Authentication cookies
- Tokens
- Unnecessary personal data

Sensitive data is redacted before evidence generation in discovery, and replay/handoff do not collect sensitive data.

## Limitations

- Evidence is file-based only (not database-backed)
- Screenshot generation is not automatic for all actions
- Live Mariner Pro evidence may not be available if the environment is not configured
- Evidence is organized by timestamp, not by capability or tenant
